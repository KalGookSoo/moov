# moov 화면 흐름

주요 유즈케이스별로 사용자가 화면을 어떻게 이동하며 작업을 완료하는지 정의한다. 화면 계층 구조는 [information-architecture.md](./information-architecture.md) 참고.

## UC-01. 운동 세션 기록

```mermaid
flowchart TD
    A["세션 목록"] -->|"+ 버튼"| B["세션 작성 (날짜 입력)"]
    B -->|"파트 추가"| C["파트 편집 (포맷 선택)"]
    C -->|"블록 추가"| D["블록 편집 (종목·무게·반복·태그)"]
    D -->|"블록 추가 반복"| C
    C -->|"결과 입력 (포맷별 입력 UI)"| E["결과 입력"]
    E -->|"파트 추가 반복"| B
    B -->|"저장"| A
```

- 파트/블록은 개수 제약이 없으므로 "파트 추가"와 "블록 추가"는 각각 반복 가능하다(FR-02, FR-03).
- 웜업처럼 결과가 없는 파트는 결과 입력을 건너뛸 수 있다(FR-04).

## UC-02 / UC-05. 세션 조회 및 컨디션 메모

```mermaid
flowchart TD
    A["세션 목록"] -->|"세션 선택"| B["세션 상세"]
    B -->|"컨디션 메모 추가"| C["컨디션 메모 입력"]
    C -->|"저장"| B
    B -->|"수정"| D["세션 작성/수정"]
    D -->|"저장"| B
```

## UC-03. 종목별/태그별 기록 추이 조회

```mermaid
flowchart TD
    A["히스토리 탭"] -->|"종목 선택"| B["종목별 히스토리 (리스트/그래프)"]
    A -->|"태그 선택"| C["태그별 집계 추이 (기간별 볼륨/빈도)"]
```

## UC-04. PR(1RM) 관리

```mermaid
flowchart TD
    A["PR 탭"] -->|"목록 조회"| B["PR 목록 (종목별)"]
    B -->|"+ 버튼"| C["PR 등록"]
    C -->|"기존 PR보다 낮은 값 입력"| D["경고 다이얼로그"]
    D -->|"그래도 저장"| B
    D -->|"취소"| C
    C -->|"저장"| B
```

## UC-06. 운동 프로그램 템플릿 관리 및 적용

```mermaid
flowchart TD
    A["템플릿 목록"] -->|"+ 버튼"| B["템플릿 편집 (파트·블록 구성)"]
    B -->|"저장"| A
    C["세션 작성"] -->|"템플릿 불러오기"| A
    A -->|"템플릿 선택"| C
    C -->|"불러온 내용 수정 후 저장"| D["세션 목록"]
```

## UC-07 / UC-08. 종목·태그 카탈로그 관리

```mermaid
flowchart TD
    A["관리 탭"] --> B["종목 카탈로그"]
    A --> C["태그 카탈로그"]
    B -->|"추가/수정/삭제"| B
    C -->|"추가/수정/삭제"| C
    D["블록 편집"] -->|"목록에 없는 종목/태그 즉시 추가"| B
    D -->|"목록에 없는 종목/태그 즉시 추가"| C
```

- 종목 삭제 시 "이미 N개 기록에 사용 중입니다" 확인 다이얼로그를 표시한다(FR-11). 태그 삭제는 별도 확인 없이 즉시 반영된다(FR-12).
