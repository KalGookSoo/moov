# moov 개요

## 프로젝트

**moov**는 크로스핏/스트렝스 트레이닝 중심의 운동 프로그램 설계와 실제 수행 기록(운동일지)을 관리하는 iOS 앱이다.

## 핵심 가치

- **유연한 세션 구조**: 세션은 하나 이상의 파트(Part)로 구성되며, 파트마다 독립적인 포맷과 결과를 가진다. "본운동이 한 세션에 여러 번(각각 다른 포맷) 등장"하는 실제 운동 패턴을 그대로 표현할 수 있다.
- **태그 기반 분류**: 웜업/본운동/보조운동은 고정된 슬롯이 아니라 블록마다 자유롭게 부여하는 태그다. 경계가 모호한 운동 구성(예: 본운동을 겸하는 빌드업)도 다중 태그로 표현한다.
- **사용자 정의 확장**: 프리셋 운동 종목·태그로 충분하지 않을 때 사용자가 직접 추가/수정/삭제할 수 있다.
- **시간 기준 성장 추이**: 종목별 기록 추이, 태그별 집계 추이, PR(1RM) 갱신 이력을 UI에서 조회할 수 있다.
