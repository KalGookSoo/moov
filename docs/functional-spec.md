# moov 기능 명세

유즈케이스([use-cases.md](./use-cases.md))를 화면/기능 단위로 분해한 기능 요구사항(FR)이다. 각 FR은 GitHub Issue(`[FR-XX]`)로도 등록된다.

## FR-01. 운동 세션 CRUD

- **개요**: 운동 세션을 생성/조회/수정/삭제한다.
- **상세 요구사항**:
  - 세션은 날짜, 운동 포맷, 웜업/본운동/보조운동 블록, 결과, 노트로 구성된다.
  - 세션 삭제 시 확인 다이얼로그를 표시한다.
- **수용 기준**:
  - Given 세션 작성 화면에서, When 필수 항목을 채우고 저장하면, Then 세션이 목록에 나타난다.
  - Given 저장된 세션이 있을 때, When 삭제를 확정하면, Then 목록에서 사라진다.
- **연관 데이터 모델**: `WorkoutSession`
- **연관 유즈케이스**: UC-01, UC-02

## FR-02. 운동 포맷 선택

- **개요**: 세션마다 운동 포맷(EMOM/AMRAP/For Time/Interval/Rounds/Strength)을 선택한다.
- **상세 요구사항**:
  - 포맷은 열거형으로 관리하며 이후 결과 입력 방식(FR-04)을 결정한다.
  - 포맷별 타임캡(선택) 입력을 지원한다.
- **수용 기준**:
  - Given 세션 작성 중, When 포맷을 EMOM으로 선택하면, Then 결과 입력 UI가 EMOM에 맞게 바뀐다.
- **연관 데이터 모델**: `WorkoutSession.format`
- **연관 유즈케이스**: UC-01

## FR-03. 운동 블록 입력

- **개요**: 웜업/본운동/보조운동 각 구간에 종목 단위 블록을 추가/수정/삭제한다.
- **상세 요구사항**:
  - 블록은 종목명, 무게, 무게 단위(lb/kg), 반복수, 세트수, 휴식시간(선택)을 갖는다.
  - 한 세션에 여러 블록을 순서대로 추가할 수 있다.
- **수용 기준**:
  - Given 본운동 섹션에서, When 종목/무게/반복수를 입력하고 블록을 추가하면, Then 블록이 목록에 순서대로 표시된다.
- **연관 데이터 모델**: `ExerciseBlock`
- **연관 유즈케이스**: UC-01

## FR-04. 결과 입력

- **개요**: 선택된 포맷에 맞는 결과 타입(시간/라운드+렙/성공-미완수/최대중량)으로 결과를 입력한다.
- **상세 요구사항**:
  - For Time/Interval → 완료 시간 또는 미완수 사유.
  - AMRAP/Rounds → 라운드 수 + 추가 렙.
  - EMOM/Strength → 성공/실패 또는 최대 중량.
- **수용 기준**:
  - Given AMRAP 포맷 세션에서, When 결과를 "3라운드 + 12reps"로 입력하면, Then 세션 상세에 해당 결과가 표시된다.
- **연관 데이터 모델**: `WorkoutResult`
- **연관 유즈케이스**: UC-01

## FR-05. 세션 목록/상세 뷰

- **개요**: 기록된 세션을 날짜 역순 목록으로 보여주고, 선택 시 상세 화면으로 이동한다.
- **상세 요구사항**:
  - 목록 항목에는 날짜, 포맷, 결과 요약이 표시된다.
  - 상세 화면에는 웜업/본운동/보조운동/결과/노트 전체가 표시된다.
- **수용 기준**:
  - Given 세션이 여러 개 있을 때, When 목록 화면에 진입하면, Then 최신 날짜 순으로 정렬되어 표시된다.
- **연관 데이터 모델**: `WorkoutSession`
- **연관 유즈케이스**: UC-02

## FR-06. 종목별 히스토리 뷰

- **개요**: 특정 종목을 선택하면 해당 종목이 등장한 모든 기록을 시간순으로 조회한다.
- **상세 요구사항**:
  - 무게/반복수 변화를 리스트 또는 그래프로 표시한다.
  - 종목명으로 검색/필터링할 수 있다.
- **수용 기준**:
  - Given "Back Squat"을 3회 기록했을 때, When 히스토리 화면에서 검색하면, Then 3건이 시간순으로 표시된다.
- **연관 데이터 모델**: `ExerciseBlock`
- **연관 유즈케이스**: UC-03

## FR-07. PR(1RM) 등록/갱신

- **개요**: 종목별 개인 기록(1RM)을 등록하고 갱신 이력을 보존한다.
- **상세 요구사항**:
  - 신규 PR 등록 시 기존 값과 비교해 갱신 여부를 표시한다.
  - 과거 PR 이력을 모두 보존해 추이를 조회할 수 있다.
- **수용 기준**:
  - Given 기존 Back Squat PR이 265lb일 때, When 275lb로 등록하면, Then 갱신으로 표시되고 이전 값도 이력에 남는다.
- **연관 데이터 모델**: `PersonalRecord`
- **연관 유즈케이스**: UC-04

## FR-08. 컨디션 노트 입력

- **개요**: 세션에 통증 부위/강도 및 자유 텍스트 메모를 남긴다.
- **상세 요구사항**:
  - 통증 부위와 강도(1~10)는 선택 입력이다.
  - 자유 텍스트 메모만 단독으로도 저장 가능하다.
- **수용 기준**:
  - Given 세션 작성 중, When 통증 강도 없이 메모만 입력하고 저장하면, Then 정상 저장된다.
- **연관 데이터 모델**: `ConditionNote`
- **연관 유즈케이스**: UC-05

## FR-09. 운동 프로그램 템플릿 CRUD

- **개요**: 반복 사용할 운동 구성을 템플릿으로 저장하고 세션에 적용한다.
- **상세 요구사항**:
  - 템플릿은 웜업/본운동/보조운동 블록 구성을 포함한다.
  - 세션 작성 시 템플릿을 불러오면 블록이 자동으로 채워지고, 이후 자유롭게 수정 가능하다.
  - 템플릿 삭제는 이미 생성된 세션에 영향을 주지 않는다.
- **수용 기준**:
  - Given 저장된 템플릿이 있을 때, When 새 세션에서 템플릿을 불러오면, Then 웜업/본운동/보조운동 블록이 자동으로 채워진다.
- **연관 데이터 모델**: `WorkoutTemplate`
- **연관 유즈케이스**: UC-06
